# AGENTS.md

## Cursor Cloud specific instructions

This is a **pure shell script repository** — a dotfiles/provisioning toolkit for Debian/Ubuntu. There is no compiled application, no build step, and no running service.

### Linting

- **shellcheck**: Lint all scripts with `shellcheck web_install.sh install/*.sh setting/*.sh`. Existing warnings are intentional (e.g. SC2016 for single-quoted `$PATH` in echo).
- **Syntax check**: `bash -n <script>` for quick syntax validation.

### Running / Testing

- The main entry point is `web_install.sh`. It requires **root** (`sudo`).
- Show usage: `sudo bash web_install.sh --help`
- Safe modules to test in a cloud VM without side-effects on the shell session: `--networktools`, `--rootkey`.
- **Destructive modules** (`--ohmyzsh`, `--all`) modify `~/.zshrc`, install oh-my-zsh, and change the default shell. Avoid running these unless you specifically need to test them, as they alter the VM's shell environment.
- `--systemtools` requires the `ppa:zhangsongcui3371/fastfetch` PPA, which may not be available on all Ubuntu versions.
- `--navi` installs Rust/Cargo toolchain and can take several minutes.

### Notes

- `install/mytheme.sh` and `install/venv.sh` are **sourced** scripts (not standalone executables). They are designed to be `source`d from `~/.zshrc`.
- The `.gitignore` is a Python template (auto-generated by GitHub); there is no Python code in this repo.
